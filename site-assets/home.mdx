## Know what you are installing

Device pages distinguish experimental ports from tested releases. Hardware
results apply to the exact image tested; a successful build alone does not
establish device support.

[Release pipelines](./pipelines/) · [Current project status](./project-status/) · [Release process](./releases/) · [Contribute](./contributing/)

## Built in the open

Porthole maintains downstream Nura device packages and a signed APK repository.
The bring-up toolkit records device checks and lessons so contributors can
reproduce the work.

Independent community project. Read [why this fork exists](./about/), including
our thanks to the Nura team and the upstream projects that make this work possible.
