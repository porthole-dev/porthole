## About this project

Porthole is the command-line toolkit for building and testing device ports. Each device page tracks its own progress; downloads appear only after release checks pass. Hardware results name the exact image tested.

See [project status](./project-status/), [release guidance](./releases/), and [contributing](./contributing/). Start a change with `make ci`.

Nura's name changed in 2026. Some package names still use `postmarketOS` for compatibility; see [naming notes](./upstream-naming/).
