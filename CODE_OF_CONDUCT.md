# Code of Conduct

This project follows the [postmarketOS Code of
Conduct](https://postmarketos.org/coc/), because porthole exists to serve that
community and contributors should not have to learn a second set of rules.

In short: be respectful, assume good faith, and remember that most people here
are volunteers doing hard work on old hardware for free.

## Reporting

Raise concerns with the maintainer at the address in the git history, or open a
GitHub issue if the matter is not sensitive.

## A note specific to this project

Bring-up work produces a lot of wrong conclusions. That is normal and expected —
the entire `brain/laws/` directory exists because of it. Correcting a finding is
never an attack on the person who made it, and nobody should be reluctant to
publish a result that later turns out to be wrong. Say what you observed, say
what you concluded, and let both be revisited.
