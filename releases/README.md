# Reviewed release evidence

This directory intentionally contains no release or hardware claims yet.
`porthole release catalog` generates device pages from the release policies
and JSON records placed here. No record means no download or working claim.

Use `docs/RELEASES.md` for the manifest and hardware-report contract. Verify
artifacts before submitting their manifest. Publication URLs must name immutable
release assets. Submit a failed-attempt record too, so a last good image does
not conceal a failed recent build. Never put images, private logs, or raw device
captures in Git. Reports and manifest updates go through review.
