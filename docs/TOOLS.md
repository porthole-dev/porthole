# Tool catalogue

Generated by `make tools-doc` from each tool's own header. Do not edit.

`porthole tools` is the searchable version of this; `porthole tools --json` is the machine-readable one.

**needs** is the device state a tool requires: `-` host-only, `BOOTED`, `FASTBOOT`, `on-device` (it runs *on* the device), or `any` (it probes and handles several).
