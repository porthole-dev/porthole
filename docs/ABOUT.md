# About Porthole

Porthole develops community device ports, build tools, and patched packages
for Nura. We started with the Google Pixel 2 XL and organize the project so
other devices can use the same build and release process.

## Why this fork exists

Nura's [contribution policy](https://docs.postmarketos.org/policies-and-processes/development/ai-policy.html)
does not accept AI-assisted contributions. Some of our downstream work uses
AI assistance, so we maintain and review it here rather than submit it against
that policy. Our [AI policy](https://github.com/porthole-dev/porthole/blob/main/AI.md)
explains disclosure and review expectations.

This is an independent community project. We do not speak for Nura or claim
its endorsement. Upstream package and repository identifiers are preserved
where compatibility depends on them.

## Thank you

Thank you to the Nura team and its contributors for pmbootstrap, pmaports,
device integration, documentation, and the years of work that make these ports
possible. We also depend on Alpine Linux, the Linux kernel community, GNOME,
Phosh, libcamera, and the maintainers of the software we package.

## Project organization

- **Devices:** profiles, boot requirements, and dated hardware evidence.
- **Downloads:** complete image assets and a browser for signed APK packages.
- **Development:** rootless builds, package recipes, and the bring-up toolkit.
- **Knowledge base:** searchable lessons and playbooks, organized by topic.
- **Release pipelines:** live workflow status, source checks, and publication.
